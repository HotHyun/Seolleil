## 한 줄 소개

국내 스키장 추천부터 리프트·렌탈·셔틀·숙박 비용 비교, 준비 체크리스트와 동행자 공유까지 한 번에 하는 스키 트립 플래너.

## 짧은 소개 (3줄, 신청서 소개란용)

설레일은 국내 스키장 13곳의 리프트권, 렌탈샵 180곳 이상, 스키버스·셔틀 정보를 한곳에 모아 날짜와 인원에 맞는 스키장과 예상 비용을 비교해 주는 웹 서비스입니다.
로그인 없이 스키 트립을 만들고, 준비물 체크리스트와 1/N 정산을 동행자와 링크로 공유할 수 있습니다.
2026/27 시즌에 오픈했으며, 가격마다 출처와 확인 상태를 표시해 신뢰할 수 있는 정보를 제공하는 데 집중합니다.

## 중간 소개 (제휴 제안서·메일용)

**설레일은 처음 스키장에 가는 사람이 "어디로, 얼마에, 무엇을 준비해서" 가야 하는지 한 번에 정할 수 있게 돕는 서비스입니다.**

- 조건 기반 추천: 출발지, 날짜, 인원, 실력, 예산으로 스키장 3곳을 비교하고 추천 이유를 보여줍니다.
- 총비용 비교: 리프트권, 렌탈(장비·의류), 교통(자차·셔틀), 숙박을 방문 날짜 기준으로 합산합니다. 모든 가격에 출처와 확인 상태(확인됨/추정)를 표시하고, 새 시즌 가격이 게시되기 전에는 지난 시즌 참고가임을 명시합니다.
- 트립 작업공간: 날짜별 렌탈샵·장비·리프트권 선택, 숙박 밤별 계획, 가는 길·오는 길 교통 선택, 준비 체크리스트, 비용 정산을 한 화면 흐름으로 관리합니다.
- 공유와 협업: 보기/편집 링크로 동행자와 일정을 공유하고, 가입 계정 초대와 권한 관리를 지원합니다.
- 스키장 가이드: 스키장별 리프트권 가격, 렌탈샵 비교, 셔틀 요금 페이지를 제공합니다(검색 유입용).

**수록 데이터 (2026-11 기준)**: 스키장 13곳, 렌탈샵 180곳 이상(지도 위치 포함), 리프트권 가격 90건 이상, 렌탈 가격 190건 이상, 스키버스·셔틀 노선, 주변 숙소 후보.

| 제휴 대상 | 노출 위치 | 사용자 행동 |
|---|---|---|
| 숙박 예약처(여기어때·NOL 등) | 트립 작업공간의 숙박 탭, 스키장별 숙박 후보 | 날짜별 숙박 후보를 비교하다가 예약 링크 이동 |

- 추천 순위와 가격 계산은 제휴 여부와 무관합니다.
