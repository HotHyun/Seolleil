# QA 체크리스트

배포 후 수동 점검용 체크리스트다.

## 비로그인 플로우

- 홈에서 `스키 트립 만들기` 진입.
- 조건 입력 후 추천 결과 표시.
- 추천 카드에서 트립 생성.
- 편집 링크 안내 배너 표시.
- 체크리스트 상태 변경 가능.
- 읽기 전용 공유 링크 재발급 가능.

## 로그인 플로우

- Google 로그인 가능.
- 내 스키 트립 목록 진입 가능.
- 로그인 상태에서 만든 트립이 내 목록에 표시.
- 비로그인 트립에서 로그인 후 내 트립에 저장 가능.
- 로그아웃 가능.

## 트립 상세

- 방문 날짜, 인원, 교통수단, 숙박비, 리프트 시간권, 렌탈 옵션 수정 가능.
- 수정 후 비용 스냅샷 재계산.
- 트립 상태 변경 가능.
- 체크리스트 항목별 외부 링크 동작.
- 가격 출처 링크 동작.

## 공유 링크

- 공유 링크는 로그인 없이 조회 가능.
- 체크리스트 상태는 보이지만 수정 불가.
- `not_needed` 항목은 노출되지 않음.
- edit link, 사용자 정보, 개인 메모, 삭제/재발급 버튼이 보이지 않음.

## 스키장/추천

- 스키장 디렉토리에서 상세 진입 가능.
- 스키장 상세에서 공식 링크, 운영현황, 리프트권, 렌탈, 지도 링크 동작.
- 추천 결과 없음 상태가 깨지지 않음.
- 렌탈 옵션 없음 상태가 깨지지 않음.

## 모바일

- 헤더 메뉴가 모바일에서 보임.
- 추천 카드의 비용/렌탈 비교 영역이 가로 스크롤 없이 표시.
- 트립 수정 폼이 1열로 표시.
- 체크리스트 상태 변경과 메모 저장 버튼이 터치 가능.
- 공유 페이지 카드가 화면 폭을 넘지 않음.
