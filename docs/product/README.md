# Korean Ski 기획 문서

이 폴더는 Korean Ski 제품 기획의 기준 문서입니다.

앞으로 대화하면서 확정되는 기획, 정책, 범위, 데이터 구조, 추천 로직은 채팅 기록에만 남기지 않고 이 폴더의 문서를 직접 수정합니다.

## 문서 목록

- `mvp.md`: MVP 범위, 타깃 사용자, 핵심 플로우, 제외 범위.
- `october-launch-roadmap.md`: 2026년 10월 런칭을 위한 월별 로드맵과 품질 기준.
- `decisions.md`: 지금까지 확정된 제품/기술 의사결정.
- `data-model.md`: 스키장, 트립, 가격, 공유 링크의 기획 단계 데이터 모델.
- `pricing.md`: 시즌별 static 가격 데이터 운영 방식과 비용 계산 정책.
- `seasonal-price-sources.md`: 25/26 시즌 가격 데이터 출처와 26/27 교체 체크리스트.
- `recommendation.md`: 룰 기반 추천 전략.
- `technical-plan.md`: 기술 스택, 배포, 운영 방향.
- `share-security.md`: 선택적 로그인, 편집 링크, 공유 링크 보안 정책.
- `analytics.md`: 성과 지표, 이벤트 수집, Umami/Appwrite 운영 정책.
- `ui-design.md`: UI 스타일링, 컴포넌트, 레이아웃 방향.
- `resort-dataset.md`: 국내 스키장 데이터셋 범위와 수집/검증 정책.
- `trip-flow.md`: 트립 생성, 추천, 옵션 선택, 저장 플로우.
- `checklist.md`: 트립 체크리스트 항목, 상태값, 진행률 정책.
