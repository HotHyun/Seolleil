# 체크리스트 정책

## 편집 UX

- 사용자 추가 항목은 이름과 메모를 수정할 수 있다.
- 기본 항목은 의미를 보존하기 위해 이름 변경과 삭제를 막고 메모 편집만 허용한다.
- 항목 추가·상태 변경·상세 수정·삭제는 Umami 사용 이벤트와 Appwrite 성공 이벤트를 구분해 기록한다.
- 트립 예산 화면에서 리프트 시간권, 렌탈 상품, 이동수단을 선택하면 해당 `확인`/`선택` 항목을 `planned`로 전환한다.
- 숙소명 또는 숙박 확정 금액을 입력하면 `숙박비 입력` 항목을 `planned`로 전환한다.
- 선택만으로 예약·결제 완료를 추정하지 않으며 `reserved`, `paid`는 사용자가 직접 표시한다.
- 결정이 필요한 항목은 비교 UI를 체크리스트 안에 중첩하지 않고 `선택·예약` 작업 공간의 해당 카테고리로 연결한다. 상세 1차 범위는 `decision-assistance.md`를 따른다.

## 기본 방향

체크리스트는 Korean Ski MVP의 핵심 기능이다.

사용자가 "내가 이걸 다 챙겼나?"를 확인할 수 있도록 기본 항목은 넓게 제공한다. 조건상 필요 없는 항목도 삭제하지 않고 `not_needed` 상태로 표시한다.

## 카테고리

체크리스트는 아래 카테고리로 구분한다.

- 예약/구매.
- 렌탈.
- 교통.
- 숙박.
- 운영 확인.
- 준비물.
- 안전/기타.
- 커스텀.

## 상태값

```ts
type TripTaskStatus =
  | "not_needed"
  | "needs_check"
  | "planned"
  | "reserved"
  | "paid"
  | "prepared";
```

표시명:

```txt
not_needed = 필요 없음
needs_check = 확인 필요
planned = 예정
reserved = 예약 완료
paid = 결제 완료
prepared = 준비 완료
```

## 상태 변경 UI

- 모바일: 바텀시트 선택.
- 데스크톱: 드롭다운 선택.

상태가 6개이므로 모바일에서 작은 드롭다운보다 바텀시트가 적합하다.

## 기본 체크리스트 항목

### 예약/구매

- 리프트권 확인.
- 리프트권 구매/예매.

### 렌탈

- 렌탈샵 선택.
- 장비 렌탈 예약.
- 의류 렌탈 예약.

### 숙박

- 숙박비 입력.
- 숙박 예약.

### 교통

- 이동 수단 확정.
- 자차 경로/주차 확인.
- 셔틀/버스 예약.
- 출발 시간 확인.

### 운영 확인

- 공식 운영현황 확인.
- 슬로프/리프트 운영 확인.
- 날씨 확인.

### 준비물

- 장갑.
- 고글.
- 헬멧.
- 보호대.
- 넥워머/마스크.
- 두꺼운 양말.
- 여벌 옷.
- 방수팩/비닐봉투.
- 보조배터리.

### 안전/기타

- 보험/응급 연락처 확인.
- 초보자 안전수칙 확인.
- 동행자 공유 링크 전달.

## 사용자 추가 항목

- 사용자는 직접 체크리스트 항목을 추가할 수 있다.
- 사용자 추가 항목은 삭제할 수 있다.
- 기본 항목은 삭제할 수 없고 `not_needed` 상태로 처리한다.

## 메모

- 항목별 메모를 지원한다.
- 예: "렌탈샵에 9시 도착", "네이버 예약 완료".
- 공유 링크에서는 개인 메모를 숨긴다.

## 진행률 계산

진행률 계산에서 `not_needed` 항목은 제외한다.
상태를 선택하면 카테고리 요약과 전체 준비 진행률을 즉시 갱신하고, 저장은 백그라운드에서 처리한다. 저장 실패 시 서버의 마지막 상태로 복구한다.

완료 기준은 카테고리별로 적용한다.

예:

- 리프트권/렌탈/교통/숙박: `reserved` 또는 `paid`면 완료로 본다.
- 준비물/안전: `prepared`면 완료로 본다.
- 운영 확인: `prepared` 또는 `needs_check`가 아닌 상태를 완료 후보로 본다.

## 마감일 정책

- MVP 체크리스트는 마감일을 노출하거나 사용자에게 설정하게 하지 않는다.
- 준비 과정이 일정 준수 스트레스로 느껴지지 않도록 상태와 메모에만 집중한다.

## 공유 링크 표시

공유 링크에서는 아래 정보를 표시한다.

- 체크리스트 항목.
- 상태.

공유 링크에서는 아래 정보를 숨긴다.

- 개인 메모.
- 편집 UI.

## 정렬

MVP에서는 카테고리별 고정 정렬을 사용한다.

사용자 지정 정렬은 MVP에서 제외한다.
