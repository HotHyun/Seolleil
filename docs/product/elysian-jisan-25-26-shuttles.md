# 엘리시안 강촌·지산 25/26 셔틀 데이터셋

최종 조사일은 2026-08-10이다. 종료된 25/26 시즌 정적 자료이며 다음 시즌에는 운영사 원문을 다시 확인한다.

## 엘리시안 강촌

- 공식 25/26 수도권 시간표를 운행 시기·시간대·차량 노선별로 분리한다. 가는 편은 비수기 새벽 2개, 성수기 새벽 7개, 성수기 오전 2개의 11개 선택지다.
- 귀가편은 가는 편의 노선과 같은 하차 조합을 역순으로 제공한다. 비수기·성수기 새벽 노선은 리조트 17:30, 성수기 오전 노선은 13:30 출발이다. 가는 편 탑승객이 없으면 해당 귀가편도 운행하지 않는 조건을 표시한다.
- 수도권 노선은 주말·공휴일 비예약제 무료 셔틀이며 노선별 1대만 배차된다. 만차 시 탑승할 수 없고 2026-02-17에는 전 노선이 운행하지 않았다.
- 공식 페이지에 남아 있는 성수기 야간선은 운행기간이 `2025-01-01~02-16`으로 표시되어 25/26 시즌과 연도가 맞지 않는다. 정확한 25/26 운행 근거가 아니므로 선택 가능한 노선에 포함하지 않는다.
- 백양리역 내부 순환은 가는 편과 오는 편을 분리하되 수십 개의 회차를 카드로 늘어놓지 않는다. 약 20분 간격의 순환 노선으로 요약하고 공식 당일 시간표 확인 조건을 유지한다.
- 춘천 시내 순환선은 리조트와 시내를 여러 차례 왕복하는 생활권 순환 노선으로, 한 회차 안에서도 승차 방향이 바뀐다. 현재의 단방향 스키 셔틀 모델에 잘못 끼워 맞추지 않고 별도 순환 교통 UX를 설계할 때 반영한다.
- 출처: [엘리시안 강촌 공식 셔틀 안내](https://www.elysian.co.kr/shuttle-bus-reservation)

## 지산리조트

- 공식 25/26 안내에서 서울시청역 2번 출구와 종합운동장역 1번 출구 유료 노선, 성인 편도 20,000원·왕복 38,000원을 확인한다.
- 각 출발지의 07:30·13:30 가는 편과 지산리조트 제1주차장 12:00·18:00 귀가편을 각각 선택 가능한 노선으로 분리한다.
- 가는 편과 오는 편의 노선 ID가 달라도 같은 운영사·원문·왕복 요금이면 1인 38,000원으로 한 번만 계산한다.
- 25/26 종료 후 예약 사이트가 응답하지 않으므로 다음 시즌에는 운행 시간과 기간을 다시 확인한다. 공식 안내가 확인해 주는 노선·요금·예약 연락처와 종료 시즌 예약표의 시간 정보를 구분해 유지한다.
