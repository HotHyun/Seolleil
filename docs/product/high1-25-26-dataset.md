# 하이원 25/26 데이터셋

최종 조사일은 2026-07-15이다. 음식점과 리조트 외부 숙박은 이번 범위에서 제외한다.

## 데이터 판정 기준

- `verified_25_26`: 업체가 공개한 25/26 가격표 또는 예약 페이지에서 품목과 가격을 직접 확인했다.
- `listed_25_26`: 25/26 예약 플랫폼 판매 목록에서 업체 존재는 확인했지만, 옵션별 최종가와 서비스 조건은 확인하지 못했다. 비용 계산에는 사용하지 않는다.
- `historical_needs_recheck`: 업체 운영과 서비스 안내는 확인했지만 25/26 가격표가 없어 방문 전 재확인이 필요하다. 비용 계산에는 사용하지 않는다.
- 픽업·배달은 공개 문구가 있을 때만 `true`로 기록한다. 단순히 리조트 인근이라는 이유로 추정하지 않는다.
- 네이버 지도 자동 접근이 차단되므로 지도 검색 링크는 재확인 경로이며, 지도 등록 업체 전체를 완전하게 보장하지 않는다.
- 가격은 성인 1인 기준 원화다. 외부샵 리프트 가격은 공개된 `리프트 단독` 가격을 사용한다.
