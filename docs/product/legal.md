# 약관·개인정보처리방침

- 페이지: `/privacy`(개인정보처리방침), `/terms`(이용약관). 푸터와 로그인·가입 화면에서 링크한다.
- 운영자 표기·문의 이메일·시행일은 `src/lib/legal.ts` 한 곳에서 관리한다. 내용을 바꾸면 시행일을 함께 갱신하고, 방침 변경 고지 기준(시행 7일 전, 불리한 변경은 30일 전)을 따른다.
- 방침에 적은 내용은 실제 동작과 같아야 한다. 아래를 바꾸면 방침도 함께 고친다.
  - 새 수집 항목이나 외부 서비스(분석, 오류 수집, 메일 발송, 지도 등)를 추가할 때
  - Firestore 저장 지역, 로그 보관 정책, 익명 트립 파기 방식이 바뀔 때
  - 계정 삭제 기능을 서비스 안에 추가할 때(현재는 이메일 요청으로 안내)
- 확인된 사실: Firestore 저장 지역은 `asia-northeast3`(서울)이다(2026-11-19 Firebase 콘솔 확인). 저장 지역이나 서비스(Firebase, Cloudflare)를 바꾸면 방침의 위탁·국외 이전 표를 고친다.
- 방침의 접속 기록 보관은 "3개월"로 적었다. 실제 설정(Cloudflare Workers Logs 등)이 이보다 길어지면 방침과 맞춘다.
- 익명 트립은 자동 파기 기능이 없어, 방침에는 "이용자가 삭제하거나 삭제를 요청할 때까지 보관"으로 적었다. 자동 파기를 만들면 방침을 함께 고친다.

## 제휴 링크

- 제휴 파라미터는 `src/lib/affiliate.ts`의 `affiliateProviders[].params`에만 둔다. 비어 있으면 링크·표기가 바뀌지 않는다. 승인 후 값을 채우고 재배포하면 해당 도메인의 외부 링크에 적용된다(`AnalyticsLink`가 변환, `rel="sponsored"` 추가).
- 제휴가 하나라도 활성화되면 `AffiliateNotice`가 숙박·렌탈 선택 화면에 대가 고지 문구를 보여준다. 새 화면에 예약·구매 링크를 추가하면 같은 고지를 함께 둔다. 약관 제10조와 내용을 맞춘다.
- 쿠팡 파트너스 등 사업자별 의무 문구가 있으면 `affiliateDisclosure`에 추가한다.
- 추천 순서·가격 계산은 제휴 여부와 무관하게 유지한다.
