# 무주 덕유산·곤지암 25/26 셔틀 데이터셋

최종 조사일은 2026-08-10이다. 종료된 25/26 시즌 정적 자료이며 다음 시즌에는 운영사 원문을 다시 확인한다.

## 무주 덕유산리조트

- 무주레져투어가 25/26 동계시즌 노선으로 명시한 군산·익산·전주 새벽선과 전주 오전선을 제공한다. 두 노선 모두 PKG 8명 이상 사전 예약제로 운영된다.
- 새벽선은 군산 06:00, 익산 06:30, 전주 07:20·07:22·07:30·07:35에 출발한다. 오전선은 전주 09:45·09:50·09:57·10:00에 출발한다. 무주 도착·귀가 승차 위치는 설천하우스다.
- 귀가편은 설천하우스 13:00와 16:30 출발을 각각 선택지로 분리한다. 13:00편은 8명 이상 예약 시, 16:30편은 예약 시 운행하며 당일 운행 여부를 운영사에 확인한다. 원문이 정확한 하차 순서를 명시하지 않아 지역별 하차 후보만 제공하고 순서는 재확인하도록 표시한다.
- 성인 교통 단독 요금은 전주 편도 20,000원·왕복 40,000원, 익산 편도 26,000원·왕복 52,000원, 군산 편도 32,000원·왕복 64,000원이다. 트립 예산에서는 가는 편과 오는 편에 선택한 지역별 편도 요금을 각각 합산한다.
- 리조트가 직접 운영하던 별도 셔틀은 공식 페이지에서 2026-03-06부터 잠정 운행 불가로 안내된다. 25/26 외부 출발 노선과 혼합하지 않는다.

## 곤지암리조트

- 공식 스키 이용 안내에는 `무료 셔틀 버스` 메뉴가 남아 있지만 연결 페이지는 삭제되어 404를 반환한다. 이를 25/26 운행 근거로 사용하지 않는다.
- 공식 대중교통 안내는 곤지암역·곤지암터미널에서 택시 또는 광주 9번 마을버스를 이용하도록 안내한다. 이는 일반 대중교통이므로 스키장 제휴 셔틀 선택지에 포함하지 않는다.
- 2025년 학회·단체행사 자료에서 확인되는 곤지암역 전용 버스와 렌탈샵 픽업은 해당 행사·업체 이용자 전용이다. 일반 방문객용 25/26 시즌 노선으로 확장하지 않는다.
- 따라서 곤지암은 `25/26 제휴 셔틀 없음` 상태를 유지한다. 사용자는 트립에서 자차 또는 고속·시외버스 등 다른 이동수단을 선택한다.
