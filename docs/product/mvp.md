# MVP 기획

## 한 줄 설명

Korean Ski는 국내 스키장 정보를 한곳에 모아 사용자의 조건에 맞는 스키장을 추천하고, 예약/결제/준비 상태를 체크리스트로 관리하는 웹 플랫폼이다.

## 타깃 사용자

### 초보/입문자

- 무엇을 준비해야 할지 모른다.
- 리프트권, 렌탈, 의류, 강습, 셔틀 정보를 따로 찾아야 한다.
- 방문 전 실수를 줄이고 싶다.

### 수도권 당일치기 이용자

- 주말, 야간, 당일치기 스키를 계획한다.
- 거리, 비용, 혼잡 가능성, 준비 시간을 비교하고 싶다.

### 친구/커플/가족 단위 방문자

- 렌탈, 강습, 교통, 숙박, 준비 상태를 정리해야 한다.
- 링크 또는 계정 초대로 동행자에게 보기/편집 권한을 나눠 줄 수 있어야 한다.

## 해결할 문제

- 국내 스키장 정보가 흩어져 있다.
- 리프트권, 렌탈, 의류, 강습, 셔틀, 숙박 예약 경로가 제각각이다.
- 초보자는 준비 순서를 모른다.
- 예약 완료, 결제 완료, 준비물 체크를 한곳에서 관리하기 어렵다.
- 공식 운영현황/슬로프 상태 페이지를 매번 다시 찾아야 한다.

## MVP 핵심 가치

사용자가 자신의 조건에 맞는 스키 트립 계획을 빠르게 만들고, 방문 전 해야 할 일을 빠뜨리지 않게 만든다.

## MVP 범위

### 포함

- 국내 운영 스키장 전체 디렉토리.
- 트립 조건 입력.
- 룰 기반 스키장 추천.
- 방문 날짜 기준 예상 비용 계산.
- 실제 비용 덮어쓰기, 추가 비용과 간단한 1/N 정산.
- 리프트권·렌탈·교통 선택을 트립 비용에 반영.
- 숙소명·예약 링크·숙박비 직접 입력.
- 시즌별 static 가격 데이터.
- 외부 렌탈샵 정보와 가격.
- 트립 생성.
- 트립 일정표 템플릿.
- 트립 체크리스트.
- 외부 예약/정보 링크.
- 공식 운영현황/슬로프 상태 링크.
- 서버 DB 기반 트립 저장.
- 선택적 로그인.
- 로그인 사용자의 내 트립 목록.
- 비로그인 트립의 계정 연결.
- 소유자용 편집 링크.
- 여러 개의 지속적인 보기/편집 공유 링크와 개별 폐기.
- 가입 계정 초대, 권한 변경과 제거.
- 모바일 웹 중심 UI.
- 데스크톱 대응 레이아웃.

### 제외

- 모바일 앱.
- 자체 결제.
- 자체 예약 확정.
- 실시간 설질/슬로프 크롤링.
- 강습 정보/강사 매칭.
- 렌탈샵 실시간 재고.
- 사용자 커뮤니티.
- 중고거래.
- 복잡한 AI 챗봇 플래너.
- 대중교통 비용 계산.
- DB 기반 가격 편집 관리자 화면. 정적 데이터 품질 화면은 포함한다.
- 프로덕션 가격 크롤러.

## UX 방향

- 첫 화면은 마케팅 랜딩보다 "스키 트립 만들기" 행동을 바로 유도한다.
- 모바일에서 조건 입력, 추천 비교, 체크리스트 업데이트가 불편하지 않아야 한다.
- 데스크톱에서는 추천 결과와 가격/체크리스트 비교가 더 넓게 보이도록 대응한다.

## 주요 화면

### 홈

- "스키 트립 만들기" CTA.
- 로그인/내 트립 진입점.
- 국내 스키장 둘러보기.
- 초보자 추천 플랜 예시.

### 내 트립

- 로그인한 사용자가 자신이 만든 트립 목록을 확인한다.
- 진행 중/완료/지난 시즌 트립을 구분한다.
- 비로그인으로 만든 트립은 edit link를 통해 접근한 뒤 계정에 연결할 수 있다.

### 조건 입력 화면

입력 항목:

- 출발지.
- 방문 날짜.
- 당일/1박 여부.
- 인원.
- 스키/보드 여부.
- 실력: 처음, 초보, 중급, 상급.
- 장비 보유 여부.
- 의류 보유 여부.
- 교통수단: 자차, 셔틀, 버스.
- 예산 범위.
- 추천 우선순위 1~3순위.
- 리프트권 시간권.
- 숙박비 직접 입력.

### 추천 결과 화면

표시 항목:

- 사용자 조건 기반 추천 스키장 3곳.
- 카테고리별 추천: 가까움, 저렴함, 초보 친화, 야간 가능, 셔틀 편리, 1박/리조트형.
- 추천 이유.
- 예상 이동 시간.
- 필요한 예약/준비 항목.
- 방문 날짜 기준 예상 비용.
- 공식 확인 링크.

### 트립 상세 화면

- 일정표.
- 외부 예약 링크.
- 준비 체크리스트.
- 진행률.
- 공식 운영현황/슬로프 상태 링크.
- 여행 선택과 실제 비용 원장.
- 숙소 직접 기록, 추가 비용, 총액 및 동일 금액 1/N 요약.
- 트립 상세는 전체 화면 폭과 높이를 활용하는 대시보드 레이아웃이며, 데스크톱 사이드바는 화면 높이를 채우고 사용자가 접거나 펼칠 수 있다.
- 선택·예약 및 비용 화면의 리프트권과 교통 선택은 세로로 배치해 각 항목에 충분한 폭을 제공한다.

### 스키장 상세 화면

- 추천 대상과 스키 여행 관점의 핵심 매력.
- 코스 구성과 풍경 안내. 당일 운영 코스는 공식 현황 링크에서 최종 확인한다.
- 리프트권 가격 출처와 주변 렌탈 후보 요약.
- 공식 리프트권, 렌탈, 숙박 및 외부 지도 링크.
- 해당 스키장으로 트립을 만드는 명확한 CTA.

## 성공 지표

가장 중요한 지표:

- 트립을 만든 사용자가 체크리스트 상태를 실제로 업데이트하는가.

보조 지표:

- 트립 생성 완료율.
- 추천 결과에서 스키장 선택률.
- 체크리스트 항목 완료율.
- 외부 예약 링크 클릭률.
- 재방문율.
- 로그인 전환율.
- 로그인 사용자의 트립 재방문율.
- 사용자가 직접 추가한 메모/체크 항목 수.
