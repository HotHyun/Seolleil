# 스키장 우선 방향 (Resort-first)

2026-11-22 확정. 제품의 주 위계를 "스키장 추천"에서 "고른 스키장의 여행 준비"로 옮긴다.

## 배경

- 사용자 인터뷰에서 여러 스키장을 돌아다니는 사람보다, 가 본 곳 중 좋았던 한 곳을 매년 가는 사람이 많았다.
- 이런 사용자에게 추천은 한 번 쓰고 끝나는 기능이다. 반복 사용은 여행 준비(렌탈·숙박·체크리스트·비용)에서 생긴다.
- 추천은 신규 유입(검색 "스키장 추천")과 "어디 갈지 모르겠을 때"에 가치가 있다. 기능은 유지하고 위계만 낮춘다.

## 제품 포지셔닝

| 구분 | 이전 | 이후 |
| --- | --- | --- |
| 한 줄 정의 | 조건에 맞는 스키장을 추천하고 준비를 관리 | 가려는 스키장의 여행을 빠짐없이, 더 싸게 준비 |
| 홈 첫 질문 | 어떤 조건으로 갈까요(추천) | 어느 스키장 가세요 |
| 추천 | 1순위 진입 | "아직 못 정했다면" 보조 진입 (기능·로직 변경 없음) |
| 핵심 가치 | 스키장 선택 | 렌탈·숙박 비교, 체크리스트, 공유, 비용 가시화 |

## 핵심 가치 4축

1. **모아 보기**: 선택한 스키장의 렌탈샵, 숙박, 셔틀, 리프트권을 한곳에서 비교한다. 가격은 정적 시즌 참고 데이터이며 출처·확인일·신뢰도를 유지한다. "최저가 보장"이 아니라 "비교·참고"로 표현한다.
2. **후보 등록·공유**: 렌탈샵/숙소 후보를 트립에 등록하고 동행자에게 공유한다. 동행자가 보고 의견을 낼 수 있어야 한다.
3. **준비 체크리스트**: 챙길 것과 예약할 것을 동행자와 같이 관리한다. (`checklist.md`)
4. **비용 가시화**: 지금까지 고른 선택이 합쳐서 얼마인지 실시간으로 보여 준다. (아래)

## 비용 가시화 (이전 논의의 "홀딩")

돈을 맡아두는 기능이 아니다. 사용자가 이 여행에 **얼마를 쓰게 될지**를 선택이 바뀔 때마다 바로 알 수 있게 하는 기능이다.

- 트립의 모든 작업공간(리프트·렌탈·교통·숙박·체크리스트)에서 현재 예상 총액과 1인당 금액(`1/N`)을 상단 또는 하단 요약으로 항상 보여 준다.
- 렌탈샵, 숙소, 셔틀 선택이나 인원·날짜가 바뀌면 총액이 즉시 갱신된다. 새로고침이나 비용 화면 이동이 필요 없어야 한다.
- 항목별로 `예상(참고가)`과 `확정(사용자 입력)`을 구분해 표시하고, 미확정 비중이 크면 그 사실을 알려 준다.
- 사용자가 입력한 확정 금액은 정적 가격 변경과 무관하게 유지한다. (기존 `trip-budget.md` 가격 원칙)
- 후속 범위: 개인별 지출/송금 장부. 이 경우에도 돈은 보관·이동하지 않고 "누가 누구에게 얼마"만 계산한다.

## 사용자 플로우

신규:

```txt
홈 "어느 스키장 가세요?"
→ 스키장 선택
→ 스키장 허브 (렌탈·숙박·셔틀·리프트 비교)
→ 이 스키장으로 트립 만들기
→ 트립 작업공간 (후보 등록 · 체크리스트 · 공유 · 총액)
```

스키장을 못 고른 경우:

```txt
홈 "아직 못 정했어요"
→ 조건 입력 → 추천 결과 → 스키장 선택
→ 위 플로우와 합류
```

재방문(매년 같은 스키장):

```txt
홈 "지난 시즌 갔던 곳" (내 트립 기반)
→ 지난 트립 복제로 새 날짜 트립 시작
→ 이전 렌탈샵/숙소 후보와 체크리스트를 유지한 채 날짜·인원만 수정
```

## 홈 변경 사항

- 히어로: 스키장 선택(검색/지역/리스트)을 최상단에 둔다.
- 로그인 사용자: "내 트립"과 "지난 시즌 갔던 곳 다시 가기"를 선택 영역보다 위에 둔다.
- 추천: 히어로 아래 보조 섹션 "어디 갈지 모르겠다면"으로 이동한다. 문구와 `/plan`, `/recommendations` 라우트는 유지한다.
- 가치 소개: 추천 중심 카피를 렌탈·숙박 비교, 공유 체크리스트, 비용 가시화 중심으로 바꾼다.

## 변경하지 않는 것

- 추천 로직, 점수, 라우트, SEO 랜딩. (`recommendation.md`)
- 결제·예약 대행, 돈 보관, 실시간 재고/가격 제외 원칙.
- 익명 트립, 공유 토큰/초대 보안 정책.

## 구현 단위 (제안 순서)

1. (완료 2026-11-22) 홈 위계 변경과 카피 교체. 추천은 보조 섹션으로 이동.
2. (완료 2026-11-22) 스키장 상세를 "스키장 허브"로 정리: 리프트·렌탈·숙박·셔틀 앵커 내비, 숙박 찾기 카드, 트립 만들기 CTA 문구 강화.
3. 트립 전역 비용 요약 바(실시간 총액, 1/N, 예상/확정 구분).
4. 지난 트립 복제로 새 시즌 트립 시작, 홈의 "지난 시즌 갔던 곳".
5. 렌탈샵/숙소 후보 등록·공유 UX.
6. (후속) 개인별 지출/송금 장부.

## 성공 지표

- 홈 → 스키장 선택 → 트립 생성 전환율. (추천 경유 대비 비교)
- 트립당 렌탈/숙소 후보 등록 수와 공유 링크 사용률.
- 재방문 사용자의 트립 복제 사용률, 전년 대비 재방문 트립 수.
- 추천 페이지 유입의 트립 생성 전환율은 별도로 유지 관찰한다.
