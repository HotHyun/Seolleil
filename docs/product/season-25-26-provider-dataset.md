최종 조사일은 2026-07-15이다. 하이원 상세 내용은 `high1-25-26-dataset.md`에서 별도로 관리한다. 음식점과 리조트 외부 숙박은 범위에서 제외한다.

## 원칙

- 공식 숙박은 리조트가 직접 운영하거나 공식 단지 안에서 예약하는 호텔·콘도만 저장한다.
- 공식 렌탈은 실제 운영 여부가 확인되어도 25/26 공개 가격을 확보하지 못하면 `listed_25_26`로 기록하고 비용 계산에서 제외한다.
- 외부 렌탈샵은 자체 사이트 또는 25/26 예약 상품을 직접 연결한다. 포털 검색 결과 페이지는 예약 링크로 사용하지 않는다.
- `verified_25_26` 가격만 추천 비용 계산에 사용한다. `~원` 시작가, 옵션을 열어야 확정되는 가격, 과거 시즌 가격은 계산에서 제외한다.
- 사이트와 지도는 서로 다른 목적이다. 사이트는 가격·예약 확인, 지도는 위치 확인 액션으로 분리한다.
- 네이버 지도 상세 장소 ID는 자동 수집이 차단되므로 주소가 확인된 업체는 주소 검색 링크를 사용한다. 나머지는 운영자가 전달하는 정확한 장소 링크로 교체한다.
