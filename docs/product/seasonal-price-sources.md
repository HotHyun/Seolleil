# 25/26 시즌 가격 출처

이 문서는 `src/data/prices.ts`에 반영한 2025/26 시즌 가격 데이터의 출처 목록이다.

2026/27 시즌 가격이 확인되지 않은 항목은 25/26 시즌 출처 기반 값을 `25/26 참고가`로 유지하며, 26/27 방문 날짜의 비용 계산에는 같은 날짜의 25/26 가격을 추정 신뢰도로 합산한다(`src/lib/season-fallback.ts`). 같은 리조트·렌탈샵에 26/27 규칙이 등록되면 자동으로 26/27 가격만 쓴다. 정책 상세는 `pricing.md`를 따른다.

## 26/27 가격 반영 — 2026-11-19

공식 페이지에 26/27 가격이 게시된 모나용평과 알펜시아의 리프트·공식 렌탈을 `src/data/prices.ts`에 `2026-2027` 규칙으로 등록했다. 25/26 규칙과 같은 라벨·구분을 써서 전환 보드가 대체 관계로 인식한다. 시즌패스, 얼리버드·개장 특가, 슬로프 1면 운영 특가는 정상가가 아니므로 규칙으로 만들지 않았다.

- 모나용평 리프트(대인/소인): 4시간 79,000/69,000, 6시간 89,000/79,000, 8시간 99,000/89,000(앱의 `full_day`). 유효 기간은 개장일 2026-11-22부터이며, 폐장일 공지가 없어 종료일은 2027-03-31로 두었다. 2시간·3시간·야간권은 26/27 표에 없어 등록하지 않았다.
- 모나용평 렌탈: 일반 장비 4시간 44,000원(대인)~8시간 54,000원, 의류 한벌 주간 33,000원~주간+야간 50,000원. 고급 장비·부분 렌탈·연일권은 대표값에서 제외했다.
- 알펜시아 리프트(대인/소인): 오전·오후권(4시간) 59,000/48,000, 야간권 46,000/35,000, 주간권(8시간, `full_day`) 76,000/57,000, 후야권(7시간) 76,000/57,000. 개장일이 '오픈일'로만 표기되어 시작일은 2026-12-01, 종료일은 2027-03-07로 두었다. 2시간·3시간·6시간은 등록하지 않았다.
- 알펜시아 렌탈: 스키·보드 반일 32,000원~당일 50,000원, 의류 세트 반일 20,000원~당일 35,000원. 렌탈 표에는 시즌 표기가 없지만 같은 페이지의 운영 일정이 26/27이다.

같은 날 확인했지만 등록하지 않은 항목:

- 휘닉스: 26/27 리프트 얼리버드 상품(2026-11-03~11-22 판매, 6시간 64,400원, 4시간 57,900원, 장비 렌탈 포함 시 77,400원·70,900원)은 할인 상품이어서 `announcedFacts` 후보로만 남긴다. 정상가와 일반 렌탈 가격은 텍스트로 공개되지 않았다.

## 신뢰도 기준

- `confirmed`: 공식 페이지 또는 렌탈샵 페이지에서 텍스트 가격을 확인한 값.
- `estimated`: 공식/예약처/정리 자료 링크는 확보했지만 이미지, 동적 페이지, 할인 상품, 패키지 중심이라 정상가 재검증이 필요한 값.
- 모든 항목은 `sourceUrl`, `lastCheckedAt`, `verifiedByHuman`, `verificationNote`를 코드 데이터에 남긴다.

## 26/27 시즌 교체 체크리스트

1. `/admin/data-quality`에서 P1 → P2 → P3 순으로 조사하며, 현재 전체 39개 범주의 다음 재확인은 2026-11-01이다.
2. 각 리조트 공식 리프트/렌탈 페이지와 셔틀 운영사의 26/27 공지 여부를 확인한다.
3. 25/26 규칙을 삭제하지 않고 시즌이 `2026-2027`인 가격 규칙과 시즌이 `26/27`인 셔틀 노선을 추가한다.
4. 예약처 가격이 정상가인지 할인/얼리버드/패키지 가격인지 구분한다.
5. 리프트 시간권 매핑을 앱의 `2h`, `3h`, `4h`, `6h`, `night`, `full_day` 옵션에 맞춘다.
6. 공식 렌탈과 외부 렌탈샵의 장비·의류·패키지 가격을 각각 갱신한다.
7. 모든 항목에 출처명·출처 URL·`validFrom`·`validTo`·`lastCheckedAt`·신뢰도를 기록한다. 구조가 달라 자동 대응되지 않으면 `replacementKey`를 지정한다.
8. 확인 중인 항목은 `estimated`, 확정 항목은 `confirmed`, 공식 미판매 항목은 `unavailable`로 구분한다.
9. 전환 보드에서 해당 카테고리가 `confirmed` 또는 `unavailable`인지 확인한다.
10. 모든 리조트 전환이 끝난 뒤에만 `CURRENT_SEASON`을 갱신한다.
11. `pnpm data:validate`, `pnpm data:report`, `pnpm typecheck`, `pnpm test`를 실행한다.

26/27 셔틀은 `src/data/ski-shuttles/routes-26-27.ts`에 별도 등록한다. `dataStatus`는 `confirmed`, `route_only`, `unavailable` 중 하나를 사용하고, 기존 25/26 노선은 전환 완료 전까지 보존한다.
