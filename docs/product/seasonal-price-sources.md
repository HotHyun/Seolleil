# 25/26 시즌 가격 출처

이 문서는 `src/data/prices.ts`에 반영한 2025/26 시즌 가격 데이터의 출처 목록이다.

2026년 5월 기준 2026/27 시즌 가격은 아직 공개 전이므로, 25/26 시즌 출처 기반 값을 임시 운영 데이터로 사용한다.

## 신뢰도 기준

- `confirmed`: 공식 페이지 또는 렌탈샵 페이지에서 텍스트 가격을 확인한 값.
- `estimated`: 공식/예약처/정리 자료 링크는 확보했지만 이미지, 동적 페이지, 할인 상품, 패키지 중심이라 정상가 재검증이 필요한 값.
- 모든 항목은 `sourceUrl`, `lastCheckedAt`, `verifiedByHuman`, `verificationNote`를 코드 데이터에 남긴다.
