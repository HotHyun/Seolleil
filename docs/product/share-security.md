# 공유 링크/보안 정책

## 기본 원칙

Korean Ski MVP는 로그인 없이 동작한다. 따라서 편집 링크와 공유 링크가 사실상의 접근 권한 역할을 한다.

## URL 구조

편집 링크:

```txt
/trips/{editToken}
```

공유 링크:

```txt
/share/{shareToken}
```

## 토큰 정책

- 토큰 형식: nanoid 21자.
- editToken과 shareToken은 서로 다른 값으로 생성한다.
- DB에는 원문 토큰을 저장하지 않고 토큰 해시만 저장한다.
- 서버는 요청 토큰을 해시한 뒤 DB의 해시와 비교한다.

## 권한 정책

### 편집 링크

편집 링크로 가능한 작업:

- 트립 조회.
- 체크리스트 상태 수정.
- 사용자 입력값 수정.
- 숙박비 직접 입력/수정.
- 트립 삭제.

편집 링크에서 보여야 할 안내:

```txt
이 링크를 가진 사람은 트립을 수정할 수 있습니다.
```

### 공유 링크

공유 링크는 읽기 전용이다.

공유 링크에서 볼 수 있는 정보:

- 일정.
- 체크리스트.
- 예약/준비 상태.

공유 링크에서 불가능한 작업:

- 체크리스트 수정.
- 트립 조건 수정.
- 숙박비 수정.
- 트립 삭제.
- 개인 메모 조회.

## 공유 UX

- 기본 공유 버튼은 읽기 전용 공유 링크만 복사한다.
- 편집 링크를 직접 복사할 수는 있지만, 수정 권한 안내를 명확히 보여준다.

## 시즌 종료 후 정책

시즌 종료 후:

- 트립 읽기는 가능하다.
- 트립 수정은 비활성화한다.
- 오래된 가격/운영 정보가 현재 정보처럼 보이지 않도록 시즌 정보를 표시한다.

## 검색엔진 정책

공유 링크와 편집 링크 모두 검색엔진 색인을 차단한다.

권장:

```html
<meta name="robots" content="noindex,nofollow" />
```

## 삭제 정책

- MVP에서는 편집 링크에서 트립 삭제가 가능하다.
- 삭제 후 editToken/shareToken은 더 이상 사용할 수 없다.
- 삭제된 트립의 공유 링크는 삭제 또는 만료 안내 페이지를 보여준다.
