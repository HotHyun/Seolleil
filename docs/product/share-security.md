# 공유 링크/보안 정책

## 기본 원칙

Korean Ski MVP는 선택적 로그인을 제공한다.

1차 인증 제공자는 Google OAuth다. Kakao OAuth와 이메일 매직링크는 추후 확장으로 둔다.

비로그인 사용자도 트립을 만들 수 있으며, 이 경우 편집 링크와 공유 링크가 접근 권한 역할을 한다.

로그인 사용자는 계정에 연결된 트립을 "내 트립" 목록에서 다시 열 수 있다. 편집 링크와 공유 링크는 로그인 도입 후에도 유지한다.

## URL 구조

편집 링크:

```txt
/trips/{editToken}
```

공유 링크:

```txt
/share/{shareToken}
```

내 트립:

```txt
/my-trips
```

## 토큰 정책

- 토큰 형식: nanoid 21자.
- editToken과 shareToken은 서로 다른 값으로 생성한다.
- DB에는 원문 토큰을 저장하지 않고 토큰 해시만 저장한다.
- 서버는 요청 토큰을 해시한 뒤 DB의 해시와 비교한다.

## 권한 정책

### 로그인 사용자

로그인 사용자는 계정에 연결된 트립에 대해 편집 권한을 가진다.

가능한 작업:

- 내 트립 목록 조회.
- 트립 조회.
- 체크리스트 상태 수정.
- 사용자 입력값 수정.
- 숙박비 직접 입력/수정.
- 트립 삭제.

비로그인으로 생성한 트립은 edit link로 접근한 뒤 로그인하면 계정에 연결할 수 있다.

### 편집 링크

편집 링크로 가능한 작업:

- 트립 조회.
- 체크리스트 상태 수정.
- 사용자 입력값 수정.
- 숙박비 직접 입력/수정.
- 트립 삭제.

편집 링크에서 보여야 할 안내:

```txt
이 링크를 가진 사람은 트립을 수정할 수 있습니다.
```

### 공유 링크

공유 링크는 읽기 전용이다.

공유 링크에서 볼 수 있는 정보:

- 트립명.
- 방문 날짜.
- 인원.
- 교통수단.
- 준비 진행률.
- `not_needed`가 아닌 체크리스트 항목과 예약/준비 상태.

공유 링크에서 불가능한 작업:

- 체크리스트 수정.
- 트립 조건 수정.
- 숙박비 수정.
- 트립 삭제.
- 개인 메모 조회.
- edit link 조회.
- 로그인 사용자 정보 조회.

## 공유 UX

- 기본 공유 버튼은 읽기 전용 공유 링크만 복사한다.
- 편집 링크를 직접 복사할 수는 있지만, 수정 권한 안내를 명확히 보여준다.
- 비로그인 사용자의 트립 상세에는 "로그인하고 내 트립에 저장" CTA를 표시한다.
- 로그인 사용자의 트립 상세에는 "내 트립에 저장됨" 상태를 표시한다.

## 시즌 종료 후 정책

시즌 종료 후:

- 트립 읽기는 가능하다.
- 트립 수정은 비활성화한다.
- 오래된 가격/운영 정보가 현재 정보처럼 보이지 않도록 시즌 정보를 표시한다.

## 검색엔진 정책

공유 링크와 편집 링크 모두 검색엔진 색인을 차단한다.

내 트립 화면도 검색엔진 색인을 차단한다.

권장:

```html
<meta name="robots" content="noindex,nofollow" />
```

## 삭제 정책

- MVP에서는 편집 링크에서 트립 삭제가 가능하다.
- 삭제 후 editToken/shareToken은 더 이상 사용할 수 없다.
- 삭제된 트립의 공유 링크는 삭제 또는 만료 안내 페이지를 보여준다.
