# 트립 선택·예산·정산

## 목표

추천에서 끝나지 않고 사용자가 리프트권, 렌탈, 교통, 숙소와 추가 비용을 확정하면서 한 번의 스키 여행을 끝까지 관리하게 한다.

## 1차 범위

- 리프트 시간권, 렌탈샵/상품, 교통수단 선택을 트립 예산 화면에서 변경한다.
- static 시즌 가격으로 예상 비용을 다시 계산한다.
- 리프트, 렌탈, 교통, 숙박의 실제 금액을 사용자가 덮어쓸 수 있다.
- 숙박은 주변/공식 숙박 링크만 제공하고, 숙소명·예약 링크·실제 비용은 사용자가 입력한다.
- 식비, 주유, 통행료, 주차, 추가 교통, 기타 비용을 자유롭게 추가·삭제한다.
- 총액과 사용자가 정한 인원 기준의 동일 금액 `1/N`을 보여준다. 개인별 지출/송금 장부는 후속 범위다.
- 공유 편집 권한을 가진 동행자도 수정할 수 있다.
- 숙소 정보가 입력되면 관련 체크리스트를 `planned`로 전환한다.

## 가격 원칙

트립 생성 당시 추천 비용 snapshot을 기준선으로 보존한다. 사용자가 입력한 확정 금액은 snapshot보다 우선하며, static 가격 데이터가 배포로 바뀌어도 확정 금액은 유지한다. 실제 결제나 예약 완료를 플랫폼이 추정하지 않는다.

## 제외

- 숙박 실시간 가격/재고 및 예약 대행.
- 렌탈 실시간 재고와 인앱 결제.
- 사용자별 지출 귀속, 송금 요청, 복잡한 정산 채권 관계.
- 맛집 추천 및 네이티브 앱.

## 운영

리프트·렌탈 가격과 교통/숙박 링크는 기존 static 데이터와 출처 정책을 따른다. `/admin/data-quality`에서 리프트·렌탈 신뢰도와 함께 셔틀/숙박 링크 커버리지를 확인한다.
