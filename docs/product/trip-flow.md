# 트립 생성 플로우

## 기본 흐름

```txt
홈
→ 조건 입력
→ 추천 결과
→ 스키장/렌탈 옵션 선택
→ 트립 생성
→ 트립 상세/체크리스트
```

로그인은 선택 사항이다. 비로그인 사용자는 바로 트립을 만들 수 있고, 로그인 사용자는 만든 트립이 "내 트립" 목록에 저장된다.

## 저장 시점

트립은 사용자가 스키장을 선택하고 "트립 만들기"를 클릭하는 시점에 DB에 저장한다.

정책:

- 조건 입력 시작 시점에는 서버에 저장하지 않는다.
- 추천 결과 표시 시점에도 서버에 저장하지 않는다.
- 트립 생성 전 임시 저장은 MVP에서 제외한다.
- 로그인 사용자가 트립을 생성하면 계정에 즉시 연결한다.
- 비로그인 사용자가 트립을 생성하면 edit link를 발급하고, 이후 로그인 시 계정에 연결할 수 있다.

## 로그인/내 트립 흐름

### 비로그인 사용자

```txt
트립 생성
→ edit link 발급
→ 트립 상세에서 "로그인하고 내 트립에 저장" CTA 표시
→ 로그인 완료
→ 해당 트립을 계정에 연결
→ 내 트립 목록에서 접근 가능
```

### 로그인 사용자

```txt
로그인
→ 트립 생성
→ userId가 연결된 트립 저장
→ 내 트립 목록에서 재접근
```

### 내 트립 목록

- 전체/다가오는 트립/지난 트립 개수를 요약해서 표시한다.
- 다가오는 트립을 먼저 표시한다.
- 지난 트립은 별도 섹션으로 구분한다.
- 트립 이름이 없으면 스키장명 + 방문 날짜로 표시한다.
- 각 트립 카드에는 방문 날짜, 인원, 교통수단, 체크리스트 완료 개수, 준비 진행률을 표시한다.
- 공유 링크가 아니라 본인 편집 권한으로 트립 상세에 진입한다.

## 조건 입력 단계

조건 입력은 3단계 폼으로 구성한다.

### 1단계: 일정/이동

- 방문 날짜.
- 출발지.
- 인원.
- 당일/1박 여부.
- 교통수단: 자차, 셔틀, 버스.

### 2단계: 사용자 상태

- 실력: 처음, 초보, 중급, 상급.
- 스키/보드 여부.
- 장비 보유 여부.
- 의류 보유 여부.

### 3단계: 비용/선호

- 예산 범위.
- 추천 우선순위 1~3순위.
- 리프트권 시간권.
- 숙박비 직접 입력.

## 추천 결과

추천 결과에서는 아래 정보를 보여준다.

- 사용자 조건 기반 추천 스키장 3곳.
- 항목별 예상 비용 요약.
- 총 예상 비용 범위.
- 추천 이유.
- 필요한 예약/준비 항목.
- 공식/예약/렌탈 링크.

상세 가격표는 추천 결과에서 과하게 펼치지 않고, 옵션 확인 화면이나 트립 상세에서 확인한다.

## 스키장/렌탈 옵션 선택

추천 카드에서 바로 트립을 생성하지 않는다.

흐름:

1. 추천 카드에서 스키장을 선택한다.
2. 옵션 확인 화면으로 이동한다.
3. 렌탈샵과 렌탈 옵션을 선택할 수 있다.
4. 선택하지 않고 건너뛸 수도 있다.
5. "트립 만들기"를 클릭하면 DB에 저장한다.

## 렌탈샵 선택 정책

- 렌탈샵 선택은 필수가 아니다.
- 선택 전 총액은 가격 범위로 표시한다.
- 렌탈샵/옵션을 선택하면 선택 옵션 기준으로 총 예상 비용을 다시 계산한다.

## 숙박비 정책

- 숙박비는 조건 입력 단계에서 직접 입력할 수 있다.
- 입력하지 않아도 트립 생성은 가능하다.
- 트립 상세에서 나중에 입력하거나 수정할 수 있다.

## 리프트권 시간권

- 리프트권 시간권은 조건 입력 단계에서 사용자가 직접 선택한다.
- 시간권은 가격 계산에 사용한다.

## 체크리스트 생성

트립 생성 시 모든 기본 체크리스트 항목을 생성한다.

조건에 따라 필요 없는 항목은 삭제하지 않고 `not_needed` 상태로 표시한다.

이유:

- 사용자가 "내가 이걸 챙겼나?"를 전체 목록 기준으로 확인할 수 있게 하기 위해.
- 초보자가 놓치기 쉬운 항목을 숨기지 않기 위해.

## 트립 수정 정책

트립 생성 후 아래 값을 수정할 수 있다.

- 날짜.
- 인원.
- 교통수단.
- 렌탈샵/렌탈 옵션.
- 숙박비.
- 리프트권 시간권.

수정 후에는 현재 static 가격 데이터 기준으로 비용 스냅샷을 다시 계산한다.

스키장, 실력, 장비/의류 보유 여부 변경은 추천/체크리스트 영향이 크므로 후속 작업에서 별도 변경 플로우로 제공한다.

트립 상태는 사용자가 수동으로 `planning`, `ready`, `completed`, `archived` 중 선택할 수 있다.

## 생성 완료 후 화면

트립 생성 후 바로 트립 상세 화면으로 이동한다.

트립 상세 상단에는 안내 배너를 표시한다.

배너 내용:

- 비로그인 상태에서는 편집 링크를 가진 사람은 트립을 수정할 수 있음.
- 비로그인 상태에서는 로그인 후 내 트립에 저장할 수 있음.
- 로그인 상태에서는 내 트립에 저장됨.
- 공유 버튼은 읽기 전용 공유 링크를 복사함.

트립 상세에는 아래 정보를 함께 표시한다.

- 예상 총액과 항목별 비용.
- 리프트권/렌탈 가격 출처, 확인일, 신뢰도.
- 선택한 렌탈 옵션.
- 현재 static 가격과 생성 당시 가격이 달라졌을 가능성이 있으면 안내.
- 리프트권 공식 확인 링크.
- 렌탈샵 예약/확인 링크.
- 네이버 지도와 공식 운영현황 링크.

체크리스트 영역은 상단에 "오늘 확인할 것" 요약을 제공하고, 카테고리별 완료 개수를 함께 표시한다.

예약/준비 체크리스트 항목에는 가능한 경우 바로 이동할 수 있는 외부 링크를 붙인다.
